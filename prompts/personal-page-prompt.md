# Personal page prompt

The prompt itself lives in exactly one place: [the build prompt on the repo front page (README)](../README.md#the-build-prompt-round-1). Copy it from there so everyone pastes the same text, and edit it there if it needs to change.

## Before you paste

1. Read the prompt once. Everywhere you see a bracketed blank, such as `[YOUR FULL NAME]`, replace it with your own answer. Keep it short and natural.
2. Not sure which hex codes to use? The palette helper under the prompt has tested combinations. Pick one row.
3. Copy the whole block with the button in its top-right corner and paste it into the Replit Agent chat.
4. Let it build. Do not interrupt it, and do not ask for changes yet. One generation is enough; you practice editing later in the workshop.
5. When it finishes, click the preview to see your page.

If something looks off, that is fine. The page is bait; the process is the deliverable.
